# Yemma Ouardia — Event Venue

An event venue website with warm visual styling, parallax imagery, and animated text. Built as a responsive React experience.

[Visit website](https://yemma-ouardia.vercel.app)

## Built with

React, TypeScript, Tailwind CSS, Framer Motion, Vite.

## Local development

Install a current Node.js version compatible with the Vite version in package.json, then run:

```sh
git clone https://github.com/nassimmsw/yemma-ouardia.git
cd yemma-ouardia
npm install
npm run dev
```

## Available commands

- `npm run dev` — start the development server.
- `npm run build` — create a production build.
- `npm run preview` — preview the production build locally.
- `npm run lint` — run ESLint.
